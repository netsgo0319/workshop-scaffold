## 이 가이드 사용법

각 **기능 페이지**에는 다음이 정리되어 있습니다.

- **기능 설명** — 이게 뭔지
- **화면에서 보이는 것** — 화면에 뭐가 나오는지
- **해볼 프롬프트** — 정확히 뭘 입력하는지 (복붙용)
- **핵심 포인트** — 왜 강력한지, 어디에 주목할지
- **관련 데이터셋** — 어떤 파일이 사용되는지
